# Viewer shell manifest

What is in `viewer-shell/`: `wraithguard-viewer`, the Wraithguard program (the cell viewer, the
mesh viewer, the Editor, and the Load order, Conflicts, Tools, Setup and Help pages), and the
crates behind it. The viewer came from Gardenfell (Robin Hjelte, MIT) and was stripped to a
viewer (`GARDENFELL.md`). Sizes and counts are as of the last regeneration of this file.

## Layout

| Path | What | License |
|---|---|---|
| `src/main.rs` | Shell entry: the program on its own, URL mode, `--cell-viewer`, the mesh viewer; the Tauri context generated once | MIT |
| `src/cellviewer/` | The window, its launch arguments, and `commands.rs`: every command the page calls (below) | MIT |
| `viewcore/` | The viewer engine: the install, the merged world, meshes, textures, sound | MIT |
| `editcore/` | The Editor: plugins as records, the queue and journal, edits, search, the Use Report, dialogue, MWScript, Verify, the patch build, Test in OpenMW | MIT |
| `ordercore/` | The load order: openmw.cfg, mlox rules, the sort and export, MOMW lists, rule authoring, cells and references resolved as the game does | MIT |
| `conflictcore/` | Conflicts: records, fields, resources, meshes, textures, the map; the mesh editor and draw order | MIT |
| `toolscore/` | The tools: Lint, Save Check, masters, Backups, tes3cmd, settings and Setup, the Help renderer | MIT |
| `landcore/` | Merge Lands and its settings files; the Land view's encoder (not a workspace member) | MIT |
| `luacore/` | OpenMW Lua read and checked: lexer, parser, checks, the API tables, Teal, charts | MIT |
| `cli/` | The `wraithguard` command line | MIT |
| `gardenfell/` | Robin Hjelte's seven engine crates, vendored unmodified with our patches (`VENDOR.md`) | MIT |
| `gardenfell-g7/` | Greatness7's `tes3` crates read into Gardenfell's types | MIT |
| `meshopt-port/` | meshoptimizer's algorithms, ported line for line | MIT |
| `ui/src/` | Page modules, concatenated in `ui/ORDER` order by `build.rs` | **GPL-2.0** silo (MGE XE shader ports) |
| `ui/assets/` | Files shipped beside the page: MGE XE's wave volume, Mermaid | GPL-2.0 silo / MIT |
| `ui/viewer_only.html` | What the viewer hides and adds over the page; the docks' styles | GPL-2.0 silo |
| `ui/tests/` | `boot.js` (the page against `wg-view-serve`, cell and mesh mode) and `editor/` (the Editor's page tests) | MIT |
| `check/` | Compile check of `main.rs` against a stub Tauri | MIT |
| `check-commands/` | Compiles `commands.rs` without Tauri; builds `wg-view-serve`, the headless engine the page tests drive | MIT |
| `capabilities/cellviewer.json` | Window permissions | MIT |

The page is a separate frontend loaded into the webview, so the GPL-2.0 silo does not reach
the MIT code. See `ui/LICENSE`, `../License/Gardenfell`, `../License/MGE-XE` and `CREDITS.md`.

## Notes

- Dropping an optional effect (SSAO, FXAA, depth of field, shadows, underwater) does not
  remove the GPL: `06_mge.js` (used by every pass) and `26_water.js` also carry MGE XE ports.
  Each part's first line says which license it carries.
- The viewer runs on the OS webview: WebView2 on Windows, WebKitGTK on Linux (the system's,
  or the GNOME runtime's in the Flatpak), WKWebView on macOS.
